This project is designed to help people apply for jobs with AI the features are these:


1- Uses Camoufox to not be detected by the sources. 

2- It has a verified template for buidling resume.

3- the resume items will be provided by the cv pdf, then the system should extract the data from it (using ai). after reading the cv, for jobs, projects, and work experience the ai should rephrase the them to cover more broad related terminology, and it should show the user the broader explainantion and get confrimation from the user.  and keep them. 

4- user can add, or edit items, afterward system should do above process for that item. 

5- based on the resume system should show list of hard skills related to user background and get confirmation from user. once they are confrimed they should be kept as bag of technical skills. 


6- After that system should as user for what job he is looking, industry or accademai, for industry system should show list of titles and positions that user is interested and gets the confrimation from user, then save as bag of positions. 



7- then system shows list of source of jobs and ask user to tick them, then system visit those websites and find the related jobs based on the user titles and backgrounds. and save jobs, then tailor cv match with that job description, and finally apply.
